Three guarantees, three layers of truth

One identity surface for every agent. No SDK secrets. No audit trail you can't verify.

01 · AUTH

OpenID Connect, audience-bound

The resource server verifies every token against the AS's public JWKS — it holds no signing key. A token minted for /api is refused at /mcp.

02 · REDACTION

PII never leaves the service

Every log record is redacted at creation. Raw identities, money, and tokens stay inside — and never reach the agent's context window.

03 · DATABASE

The database says no

Row-level security + column grants + a separate agent pool mean an agent's delete is refused by Postgres. rows=0, nothing changed.
